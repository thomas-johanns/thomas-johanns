## Hi, I'm Thomas Johanns

Computer Engineering student at the **University of Connecticut** (B.S., expected May 2027). I like working where hardware meets software: processor design, embedded systems, vehicle networks, and AI tools for engineering.

### What I'm working on

- **Agentic AI for Systems Engineering** (senior design, Fall 2026 – present)
  AI agent workflows that turn written system requirements into SysML v2 design models, checked by the official SysML v2 validator. I lead a three-person team, build and test Langflow workflows with locally hosted LLMs (Ollama), and verify agent output in Jupyter notebooks.
- **Atlas SoC** (Summer 2026 – present)
  A 32-bit, five-stage pipelined RISC-V (RV32I) processor in SystemVerilog, built as the base of a custom system-on-chip: instruction fetch, branch and jump control, pipeline stalls, memory-mapped peripherals, and simulation testbenches.
- **CAN bus security research** (undergraduate research, Fall 2026 – present)
  A multi-microcontroller Controller Area Network test environment for studying how electronic control units communicate and where vehicle networks are exposed to unauthorized access.

### Earlier projects

- **Tamy: Autonomous Color-Seeking Robot** (Spring 2026): AVR128DB48 robot that navigates toward colored targets using a BNO055 orientation sensor and a TCS34725 color sensor, with PWM motor and arm control and compass-based heading correction.
